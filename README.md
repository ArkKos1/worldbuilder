# Worldbuilder

A desktop application for creating, editing, and scientifically simulating worlds, including worlds for Dungeons & Dragons. Planned features include building a world's geological history with guidance to help maximize scientific plausibility; drawing terrain using built-in palettes; modeling climate, temperature, and precipitation based on terrain, latitude, ocean currents, and other factors; and creating rivers, ecoregions, countries, cultures, languages, and more.

The initial versions will focus on geology, terrain, and climate.

**Status**: Early development  
**Tech stack**: Python, PySide6, NumPy, pyproj, SciPy  
**Documentation languages**: English, Russian
