# Worldbuilder
Настольное приложение, для создания, редактирования и научного моделирования миров, в том числе и для днд. В программе планируется реализовать: создание геологической истории мира с подсказками для максимальной достоверности, рисование рельефа с помощью встроенный палитр, моделирование типа климата, температуры и осадков, исходя из рельефа, широты, течений и т.д., создание рек, экорегионов, стран, культур, языков и т.д. 
Первые версии будут сфокусированы на геологии, рельефе и климате

**Статус**: ранняя разработка
**Стек**: Python, PySide6, NumPy, pyproj, SciPy
**Языки документации**: английский, русский
